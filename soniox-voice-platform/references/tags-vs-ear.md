# Tags vs ear (LiveKit Amina phone, 2026-08)

Allow-list: `[warm] [calm] [curious] [sincerely] [reassuringly] [softly] [pause]`.

If every LLM turn starts `[warm]` and sentences are the same length, the callee hears **no emotion** and **equal pauses**. Tags being “online” does not fix that.

- Vary the first tag. `[pause]` only when the topic changes.
- Do not add `[happy]` / `[laughs]` on this stack.
- Voice **id** (Nina, Daniel) ≠ persona (Amina, Mujo).
- Maya + `tts-rt-v2` = HTTP 400.
