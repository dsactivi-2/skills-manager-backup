# Soniox-Tags (englisch, vor der bosnischen Satz)

Erlaubt: `[warm] [calm] [curious] [sincerely] [reassuringly] [softly] [pause]`

Verboten: `[happy] [laughs] [excited]` und alles andere (kann vorgelesen werden).

Opener: erstes Token `[warm]`. Max ein Tag pro Antwort.

Bindestriche in Namen (`Mu-jo`, `Ami-na`) verboten.

Schreiben: latinica. Hören in BiH: latinica + ćirilica. Soniox `bs` liest keine Ćirilica.
