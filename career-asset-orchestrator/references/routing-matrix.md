# Routing Matrix

## Primary skills

| User need | Primary skill | Secondary skills |
|---|---|---|
| LinkedIn optimization | `agentkit-seo-linkedin` | `linkedin-profile-optimizer` |
| CV or ATS optimization | `agentkit-seo-cv-ats` | `resume-ats-optimizer`, `resume-bullet-writer`, `resume-tailor` |
| Portfolio website | `agentkit-seo-web-portfolio` | `portfolio-case-study-writer`, `cloudflare-deploy` |
| Job-specific application | `job-description-analyzer` | `resume-tailor`, `cover-letter-generator` |
| Job search | `job-search-mcp` | none by default |
| Final file export | `paperjsx` | none by default |

## Sequencing rules

1. Analyze before rewriting.
2. Rewrite before exporting.
3. Publish only after content and proof are stable.
4. Search jobs only after positioning is clear enough.
