# Sales pacing — no hard-sell in first 10s

## Bad (user complaint)
Open with: sell product → COD → ship → any questions?

## Good phase map
1. greeting TTS: identity only  
2. startCall: who/why one line + time permission  
3. discovery: need, one Q/turn  
4. pitch: 1–2 benefits mapped to discovery  
5. order/COD/address/readback only after interest edge  

## Graph
No edge `startCall/open → order/confirm`.  
Open success: continue | later | refuse | wrong number only.

## globalNode ban (early call)
- order/COD as first CTA  
- "any questions?" as default pitch filler  
- price dump before discovery  

## Test
First 30s must not contain order/COD/shipping close.
