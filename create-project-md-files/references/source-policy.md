# Fresh Source Policy

At every activation, create one fresh source snapshot before giving advice or
drafting content. Do not reuse remembered documentation as authority.

1. Search and open current official OpenAI Codex documentation for the selected
   file type and its discovery/configuration behavior.
2. Check the official OpenAI Cookbook for a relevant current pattern. If none
   applies, report that rather than forcing an unrelated example.
3. Check a first-party OpenAI repository only when it is relevant to the file
   type or behavior in question; read only the necessary files.

Use the same snapshot for follow-up questions during that activation. Fetch a
new targeted source only if the user changes to a file type not covered by the
snapshot, asks for a refresh, or the source is insufficient.

Never treat third-party repositories, copied templates, or search snippets as
authority. If fresh official sources cannot be reached, explain the gap and do
not claim current best practice.
